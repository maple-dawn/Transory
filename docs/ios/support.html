Transory for iPhone 支持

遇到问题或有建议，请在 GitHub Issues 提交，注明是 iPhone 版、系统版本和使用的 AI 服务。

常见问题

需要付费吗？App 本身不收费。翻译使用你自己的 API Key，费用由对应的 AI 服务商按其价格向你收取。

在哪里获取 API Key？在 DeepSeek、Anthropic（Claude）、Google AI Studio（Gemini）或 OpenAI 的开发者平台注册后创建，然后在「设置 › 模型服务」中填写。

提示「尚未填写 API Key」或请求失败？检查 Key 是否正确、账户是否有余额，以及模型名是否可用。可以在服务详情中点「从服务商获取模型列表」验证。

怎么用电脑上的本地模型？在电脑上运行 Ollama 或 LM Studio 并允许局域网访问，在 App 中添加对应服务，把接口地址改成电脑的局域网 IP，例如 http://192.168.1.2:11434/v1。

我的数据会发给谁？只发给你授权的服务商。详见 隐私政策。

Transory for iPhone Support

For questions or feedback, open an issue on GitHub Issues and mention the iPhone app, your iOS version, and the AI service you use.

Is it free? The app is free. Translations use your own API key and are billed by the AI provider.

Where do I get an API key? From the developer console of DeepSeek, Anthropic (Claude), Google AI Studio (Gemini), or OpenAI. Enter it in Settings › Model Services.

Who receives my text? Only the providers you authorize. See the Privacy Policy.
